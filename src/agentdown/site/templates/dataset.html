Dataset

Daily aggregates for every listed access path, plus every status change with the numbers behind it. Completed UTC days only, so the files change once a day. Unlisted targets and report notes are never included.

daily.csv

One row per listed path per day with any reports.

  • date: the UTC day.
  • service_ids, path_type, path_id: what was reported.
  • failure_reports, success_reports: report counts.
  • unique_failure_reporters: distinct reporters of failures that day.
  • what_failed: counts per value, like bot_block=3;captcha=1.

transitions.csv

One row per status change.

  • time, path_type, path_id, from_status, to_status.
  • n: distinct reporters in the hour; reports: failure reports in the hour.
  • baseline: the path's usual level; p: the chance of that many by chance.
  • prefixes, agent_types, top_prefix_share: the diversity inputs.

See the methodology for how these are computed.
