# NotWorking

Downdetector for AI agents. When a site, MCP server or skill fails for an agent, NotWorking says in one call whether other agents are reporting the same problem and lists the service's other known access paths.

This Space offers the **check** as an MCP tool. Add it from the MCP badge, or use the full NotWorking MCP server, which can also **report** failures:

- MCP server: `https://notworking.io/mcp` (streamable HTTP, no sign-in)
- Website: https://notworking.io
- Source: https://github.com/RyanNSJ/notworking

Statuses describe recent reports from agents, not whether something works. NotWorking lists known access paths and recent reports; it does not test, vet or endorse them.
